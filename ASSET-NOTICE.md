# Merchant assets

The files in `public/personal-finance/logos/` are copied from the locally supplied Spendmap prototype's `public/logos/` directory. The original project describes its marks as local copies sourced from official brand libraries or Wikimedia/Wikipedia file pages for merchant identification.

These merchant names and images retain their respective trademark and copyright rights. They are excluded from this repository's MIT code licence. Existing SVG metadata is retained. This example does not assert ownership of the merchant marks or imply endorsement by the merchants. The local prototype did not contain a per-file source/licence register, so this notice does not invent one.

Included marks: Ackermans, Bolt, Checkers, Choice Clothing, Clicks, Clothing Junction, Engen, Fashion World, H&M, KFC, Makro, McDonald's, Pedros, Pick n Pay, Shoprite, SPAR, Uber and Woolworths South Africa.
